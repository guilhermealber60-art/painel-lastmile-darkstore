Publicar direto no GitHub

Com um token configurado, o botão Publicar envia data/orders.json.gz, data/report.json.gz e data/meta.json direto para o repositório guilhermealber60-art/painel-lastmile-darkstore — sem baixar arquivo, sem git, sem terminal. O mesmo token também publica o diagnóstico de atrasos (data/diagnostico.json).

Segurança: o token fica salvo só neste navegador (não é enviado a mim nem a ninguém além do GitHub). Crie um fine-grained token em github.com/settings/tokens, restrito ao repositório painel-lastmile-darkstore, com permissão apenas de Contents: Read and write, e defina uma expiração. Se trocar de computador ou navegador, precisa configurar de novo.
